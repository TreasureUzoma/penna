# Penna

Penna helps developers create, manage, and deliver newsletters to their audiences. It takes subscriber lists and markdown drafts, processes the delivery through AWS SES, and produces reliable email campaigns. Teams can collaborate in shared workspaces, manage custom sending domains, and monitor subscriber growth metrics natively. There is no complicated setup, just straightforward functionality that works out of the box.

## Features

- Custom Sending Domains: Verify and assign custom domains to send emails from personalized addresses rather than a shared domain.
- Collaborative Workspaces: Create teams, invite members, and assign roles to collaborate on newsletter management safely.
- Advanced Subscriber Management: Organize subscribers into dynamic segments and automatically handle one-click unsubscribes.
- External API Access: Generate scoped API keys for programmatic delivery and subscriber onboarding directly from your own applications.
- AI Content Moderation: Automatically screen outgoing email content for phishing, scams, and spam before delivery.
- Integrated Billing: Handle tiered subscriptions, seat management, and usage limits seamlessly through Paddle checkout.

## Technologies Used

| Technology                                    | Description                                                          |
| :-------------------------------------------- | :------------------------------------------------------------------- |
| [Next.js](https://nextjs.org/)                | React framework for building the client dashboard and web interfaces |
| [Hono](https://hono.dev/)                     | Ultrafast web framework for the edge used for the backend API        |
| [TypeScript](https://www.typescriptlang.org/) | Strongly typed programming language building on JavaScript           |
| [Drizzle ORM](https://orm.drizzle.team/)      | Headless TypeScript ORM for interacting with the PostgreSQL database |
| [PostgreSQL](https://www.postgresql.org/)     | Primary relational database for user and newsletter data             |
| [Redis](https://redis.io/)                    | In-memory data store utilized for robust rate limiting               |
| [AWS SES](https://aws.amazon.com/ses/)        | Cloud email service for reliable and scalable newsletter delivery    |
| [Paddle](https://www.paddle.com/)             | Payment infrastructure for managing team billing and subscriptions   |
