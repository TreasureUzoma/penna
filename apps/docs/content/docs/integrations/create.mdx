# Create Subscriber

Penna provides a simple REST API to integrate newsletter functionality directly into your application. This guide will show you how to authenticate and add subscribers programmatically.

## Authentication

All API requests must be authenticated using your newsletter's Public Key. You can find this key in your newsletter settings dashboard.

Include the key in the `x-penna-public-key` header of your requests.

```bash
x-penna-public-key: penn_your_public_key_here
```

**Important:** Your Public Key is exposed to anyone who visits your website. While it creates a seamless integration, we recommend proxying these requests through your own backend API if you want to control rate limits or add additional spam protection layers before calling Penna.

## Endpoints

### Add New Subscriber

Adds a new subscriber to your newsletter.

**Endpoint:** `POST /api/v1/external/newsletters/subscriber/new`

**Headers:**

- `Content-Type: application/json`
- `x-penna-public-key: <YOUR_PUBLIC_KEY>`

**Body:**

```json
{
  "email": "user@example.com",
  "name": "John Doe"
}
```

**Fields:**

| Field   | Type   | Required | Description                                         |
| ------- | ------ | -------- | --------------------------------------------------- |
| `email` | string | Yes      | Subscriber's email address                          |
| `name`  | string | No       | Subscriber's full name (useful for personalization) |

## Code Examples

Here is how you can integrate the "Subscribe" functionality in various languages.

### React / Next.js

```tsx title="components/newsletter-form.tsx"
import { useState } from "react";

export function NewsletterForm() {
  const [email, setEmail] = useState("");
  const [name, setName] = useState("");
  const [status, setStatus] = useState("idle");

  const subscribe = async (e) => {
    e.preventDefault();
    setStatus("loading");

    try {
      const res = await fetch(
        "https://api.penna.dev/api/v1/external/newsletters/subscriber/new",
        {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            "x-penna-public-key": "penn_abc1234567890", // Replace with your public key
          },
          body: JSON.stringify({ email, name }),
        },
      );

      if (!res.ok) throw new Error("Failed to subscribe");

      setStatus("success");
      setEmail("");
      setName("");
    } catch (err) {
      setStatus("error");
    }
  };

  return (
    <form onSubmit={subscribe} className="flex flex-col gap-2">
      <input
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Your name (optional)"
        className="border p-2 rounded"
      />
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="Enter your email"
        required
        className="border p-2 rounded"
      />
      <button
        type="submit"
        disabled={status === "loading"}
        className="bg-black text-white p-2 rounded"
      >
        {status === "loading" ? "Subscribing..." : "Subscribe"}
      </button>
      {status === "success" && <p className="text-green-500">Subscribed!</p>}
      {status === "error" && (
        <p className="text-red-500">Something went wrong.</p>
      )}
    </form>
  );
}
```

### HTML / JavaScript (Vanilla)

```html title="index.html"
<form id="newsletter-form">
  <input type="text" id="name" placeholder="Your name (optional)" />
  <input type="email" id="email" placeholder="your@email.com" required />
  <button type="submit">Join Newsletter</button>
</form>

<script>
  const form = document.getElementById("newsletter-form");

  form.addEventListener("submit", async (e) => {
    e.preventDefault();
    const email = document.getElementById("email").value;
    const name = document.getElementById("name").value;

    try {
      const response = await fetch(
        "https://api.penna.dev/api/v1/external/newsletters/subscriber/new",
        {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            "x-penna-public-key": "penn_abc1234567890",
          },
          body: JSON.stringify({ email, name }),
        },
      );

      if (response.ok) {
        alert("Successfully subscribed!");
      } else {
        alert("Subscription failed.");
      }
    } catch (error) {
      console.error("Error:", error);
    }
  });
</script>
```

### cURL

```bash
curl -X POST https://api.penna.dev/api/v1/external/newsletters/subscriber/new \
  -H "Content-Type: application/json" \
  -H "x-penna-public-key: penn_abc1234567890" \
  -d '{"email": "test@example.com", "name": "John Doe"}'
```

### Python (Requests)

```python
import requests

url = "https://api.penna.dev/api/v1/external/newsletters/subscriber/new"
headers = {
    "Content-Type": "application/json",
    "x-penna-public-key": "penn_abc1234567890"
}
data = {
    "email": "test@example.com",
    "name": "John Doe"
}

response = requests.post(url, json=data, headers=headers)

if response.status_code == 200:
    print("Subscribed successfully!")
else:
    print(f"Failed: {response.text}")
```

## Response

**Success (200):**

```json
{
  "success": true,
  "message": "Subscriber added successfully",
  "data": {
    "id": "sub_1234567890",
    "email": "test@example.com",
    "name": "John Doe",
    "subscribedAt": "2024-01-15T10:30:00Z"
  }
}
```

**Error Responses:**

```json
// Email already exists
{
  "success": false,
  "message": "Subscriber already exists"
}

// Invalid email format
{
  "success": false,
  "message": "Invalid email address"
}

// Missing required fields
{
  "success": false,
  "message": "Email is required"
}
```

## Use Cases

### Collect Names for Personalization

Including the name field allows you to personalize your newsletters:

```javascript
// In your signup form
const formData = {
  email: userEmail,
  name: userName, // Optional but recommended
};

await fetch(API_URL, {
  method: "POST",
  headers: { "x-penna-public-key": PUBLIC_KEY },
  body: JSON.stringify(formData),
});
```

Later in your newsletters, you can use the name for personalization:

- "Hi John," instead of "Hi there,"
- "Welcome John to our community!"

### E-commerce Integration

```javascript
// After checkout
await addSubscriber({
  email: customer.email,
  name: `${customer.firstName} ${customer.lastName}`,
});
```

### Event Registration

```javascript
// After event signup
await addSubscriber({
  email: attendee.email,
  name: attendee.fullName,
});
```
