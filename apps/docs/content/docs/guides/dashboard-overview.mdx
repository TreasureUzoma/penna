# Dashboard Overview

The Penna dashboard is your central hub for managing newsletters, subscribers, and analytics. This guide walks you through each section.

## Main Navigation

### Dashboard Home

Your dashboard home provides a quick overview of:

- **Total Subscribers** - Current subscriber count across all segments
- **Newsletter Sends** - Total emails sent this month
- **Open Rate** - Average open rate (coming soon)
- **Recent Activity** - Latest subscriber sign-ups and newsletter sends

### Subscribers

The Subscribers section lets you:

1. **View all subscribers** - See your complete subscriber list
2. **Search & Filter** - Find specific subscribers by email or segment
3. **Add manually** - Click "Add Subscriber" to manually add emails
4. **Export data** - Download your subscriber list as CSV
5. **Bulk actions** - Select multiple subscribers to add to segments or remove

#### Adding a Subscriber

1. Click the **"Add Subscriber"** button in the top right
2. Enter the email address
3. (Optional) Select segments to add them to
4. Click **"Create"**

#### Managing Individual Subscribers

Click on any subscriber to:

- View subscription date
- See which segments they belong to
- Add or remove from segments
- View newsletter engagement (coming soon)
- Unsubscribe or delete

### Segments

Segments help you organize subscribers into groups:

1. **Create a segment** - Click "New Segment"
2. **Name your segment** - e.g., "Beta Users", "Pro Subscribers"
3. **Add description** - Optional notes about the segment
4. **Add subscribers** - Manually add or import

Use segments to:

- Send targeted newsletters
- Organize subscribers by interest, plan, or behavior
- Track growth of specific groups

### Compose & Send

To send a newsletter via dashboard:

1. Go to **Newsletters** → **Compose**
2. **Subject line** - Write a compelling subject (avoid spam trigger words)
3. **Content** - Write your newsletter content (supports basic markdown)
4. **Preview** - Click preview to see how it will look
5. **Select recipients**:
   - All subscribers
   - Specific segments
   - Individual emails
6. **Send** - Click send (or schedule for later)

**Tip:** Preview your email on mobile and desktop before sending to ensure proper formatting.

### Analytics (Coming Soon)

Track your newsletter performance:

- Open rates
- Click-through rates
- Subscriber growth over time
- Best performing newsletters
- Engagement by segment

### Settings

#### General Settings

- **Newsletter name** - Change your newsletter name
- **Sender details** - Configure "From" name and email
- **Description** - Add a description for your newsletter

#### API Keys

- **Public Key** - Use for adding subscribers (safe to expose)
- **Private Key** - Use for sending newsletters (keep secret!)
- **Regenerate keys** - Rotate keys if compromised

#### Domain Settings

- Configure custom domains
- Verify DNS records
- Set up SPF, DKIM, DMARC for better deliverability

#### Billing

- View current plan
- Upgrade or downgrade
- View invoices
- Manage payment method

#### Team

- Invite team members
- Manage permissions
- View team activity

## Quick Actions

Most pages include quick actions in the top right:

- **Add Subscriber** - Quickly add a new subscriber
- **Compose** - Start composing a new newsletter
- **Export** - Download data as CSV
- **Settings** - Quick access to settings

## Keyboard Shortcuts

Speed up your workflow with shortcuts:

- `Cmd/Ctrl + K` - Quick search
- `Cmd/Ctrl + N` - New subscriber
- `Cmd/Ctrl + E` - Compose newsletter
- `?` - Show all shortcuts

## Tips for Dashboard Efficiency

1. **Use segments** - Organize subscribers from day one
2. **Set up custom domain early** - Better deliverability and branding
3. **Check analytics regularly** - Understand what content resonates
4. **Keep API keys secure** - Store private key in environment variables
5. **Enable 2FA** - Secure your account in Security settings
